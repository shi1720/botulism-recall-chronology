Source processing flow: 29,485 raw records; 29,485 unique recall numbers;
28,469 records with valid initiation in 2012–2025; 327 matching reason-text
records; 81 events; 75 Class I/II events in the primary comparison. The full
raw export has one invalid initiation date, outside the selected matching
cohort. There are 329 total product entries in the 81 selected events; two
do not independently match the reason substring. Including them in date
aggregation does not change any event date or primary estimate.
